Quiz Project

This is a console-based Quiz Game written in Java.
The user selects a category (Physics, Maths, Geography, or General Knowledge) and answers a set of predefined questions. The program checks each answer, keeps track of the score, and allows the user to continue with another category or exit the quiz. The project demonstrates;

• Object-oriented programming using multiple classes
• Encapsulation with private fields and public methods
• Arrays of objects
•Loops and selection statements
• User input using Scanner
• Testing using a separate test class (QuizTest)

How to Run:

Compile all files:
javac *.java

Run the quiz:
java QuizGame

Run the test class:
java QuizTest
